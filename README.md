# NARD

Веб-игра в классические короткие нарды для двух человек за одним экраном. Работает целиком в браузере: сервер, аккаунты и сеть не нужны.

## Запуск

Нужен Node.js 22 или новее.

```bash
npm install
npm run dev
```

Откройте адрес, который покажет Vite. Для проверки и сборки:

```bash
npm test
npm run build
```

## Правила и управление

Выберите фишку, затем подсвеченный пункт. Можно перетащить фишку мышью или выбрать ход с нужной костью в боковой панели. На сенсорном экране используйте нажатия. До завершения хода последнее действие можно отменить.

Реализованы начальная расстановка, первый бросок, обязательное использование костей, дубли, закрытые пункты, сбивание и бар, вывод фишек, обычная победа, марс, кокс и куб удвоения. Счёт сохраняется между партиями в открытой вкладке. Обновление страницы начинает новую сессию.

Партия локальная: игроки по очереди пользуются одним устройством. Сетевой режим и игра с компьютером не входят в эту версию.
