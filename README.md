# NARD

Локальная веб-игра в классические короткие нарды для двух человек за одним экраном. Игровая логика работает в браузере. Сервер, аккаунты и база данных не нужны.

## Быстрый запуск

Требуются Node.js 22.12 или новее и npm. Из корня проекта:

```bash
npm ci
npm run dev
```

Откройте адрес `Local`, который напечатает Vite. Обычно это `http://127.0.0.1:5173/`. Если порт занят, используйте адрес из вывода команды.

## Как играть в интерфейсе

1. Нажмите «Определить первый ход». Игра бросит по одной кости за каждого игрока и покажет, кто начинает.
2. Выберите свою фишку на поле или бар, если там есть ваши фишки. Допустимые пункты подсветятся. Нажмите пункт назначения или выберите ход с конкретной костью в боковой панели.
3. Когда все доступные ходы сыграны, нажмите «Завершить ход». Следующий игрок бросает кости. Если ходов нет, эта же кнопка передаёт очередь сопернику.
4. До завершения хода кнопка «Отменить ход» возвращает последнее перемещение. Её можно нажимать несколько раз.
5. Победа фиксируется после вывода всех 15 фишек и нажатия «Завершить ход». «Новая партия» сохраняет текущий счёт игроков.

Фишки на пунктах можно также перетаскивать мышью. Для бара и на сенсорном экране используйте нажатия. Если один пункт назначения доступен для разных костей, выберите нужную кость в боковой панели.

Полное описание реализованных правил и подсчёта очков: [Правила игры](docs/rules.md).

## Команды

| Команда | Что делает |
| --- | --- |
| `npm run dev` | Запускает локальный сервер разработки на `127.0.0.1`. |
| `npm test` | Запускает тесты игрового движка через встроенный Node.js test runner. |
| `npm run build` | Проверяет типы и собирает статические файлы в `dist/`. |

Сборку `dist/` можно разместить на статическом хостинге в корне сайта. Для игры не нужны переменные окружения и Docker. Шрифты загружаются из Google Fonts при наличии сети; при недоступности сети применяются системные шрифты.

## Состав проекта

- `src/engine.ts`: состояние доски, допустимые ходы, применение ходов и результат партии.
- `src/main.ts`: ход партии, куб удвоения, счёт и взаимодействие с интерфейсом.
- `src/style.css`: оформление поля и адаптивная раскладка.
- `src/engine.test.ts`: проверки ключевых правил движка.

Подробнее о модели данных, ходе партии и проверках: [Устройство проекта](docs/architecture.md).

## Границы текущей версии

Игроки используют одно устройство по очереди. Нет игры с компьютером, сетевых партий, аккаунтов, сохранения в хранилище и матча до заданного числа очков. Счёт сохраняется только между партиями в открытой вкладке: обновление страницы начинает новую сессию. Дополнительные турнирные правила перечислены в [Правилах игры](docs/rules.md).
